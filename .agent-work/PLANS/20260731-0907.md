# Codex Cockpit 跨平台菜单栏/系统托盘常驻计划

## Summary

- macOS 启动时显示主窗口但不出现在 Dock；Windows 启动时显示主窗口和任务栏按钮。
- 两个平台关闭主窗口都只隐藏原 WebView，保留托盘、主进程、sidecar 与 API 服务。
- 左键托盘显示、取消最小化并聚焦主窗口；右键菜单提供“打开 Codex Cockpit Lite”和“退出 Codex Cockpit Lite”。
- 只有托盘退出、`Command-Q`/`Ctrl-Q` 或系统退出事件才进入现有 sidecar 优雅关闭流程。
- 不新增设置开关、后端 API 或配置字段；首次启动固定显示窗口，不保存上次显隐状态。

## Implementation Changes

- 新建 `frontend/src-tauri/src/desktop.rs`，集中管理稳定 ID、托盘菜单、窗口显隐、桌面事件映射和退出开始行为。
- 启用 Tauri `tray-icon` feature；托盘初始化成功后才启动 backend sidecar。
- 仅拦截 `main` 窗口的 `CloseRequested`，调用 `prevent_close()` 和 `hide()`；保持现有 `ExitRequested` 清理状态机不变。
- macOS 处理 `RunEvent::Reopen`，设置 `LSUIElement=true` 与 `ActivationPolicy::Accessory`；Windows 保持窗口显示时的任务栏入口。
- macOS 使用 44×44 透明单色 template tray icon，Windows 复用现有 32×32 彩色图标。
- 退出开始后立即移除托盘并隐藏窗口，避免在 sidecar 清理期间重新打开窗口。
- 更新构建文档，明确关闭窗口与退出应用的生命周期区别及双平台验收方式。

## Interfaces and Failure Behavior

- HTTP API、配置 schema、Svelte 页面和设置页均不变化。
- 桌面模块提供初始化托盘、显示主窗口、处理关闭事件与进入退出状态的内部接口；`BackendState` 继续独占 sidecar 状态。
- 隐藏窗口不销毁 WebView，前端页面与输入状态保留；backend 启动中或失败时仍可通过托盘重开窗口并退出。
- 窗口显示失败只记录日志并保留托盘；托盘创建失败则在 sidecar 启动前终止应用启动。
- 显式退出继续复用现有优雅关闭、超时和精确 sidecar PID fallback。

## Test and Acceptance Plan

- Rust 单元测试覆盖左键托盘、右键忽略、菜单 ID、主窗口关闭策略和重复事件幂等性。
- 运行 `python3 scripts/check.py`，随后在 macOS 执行 `cd frontend && npx tauri build --bundles app`。
- 验证打包后 `Info.plist` 的 `LSUIElement=true`，并再次运行 bundle 内 sidecar smoke。
- macOS 打包应用实测启动、无 Dock、关闭后 API/PID 保持、托盘重开、`open -a` 重开及托盘退出/`Command-Q` 清理。
- Windows 主机后续实测任务栏、关闭到托盘、托盘重开和完整退出；没有 Windows 运行时证据时明确标记待验收。

## Assumptions and Maintainability

- 不加入开机自启、状态持久化、托盘状态展示、通知、Linux 托盘行为或单实例插件。
- 左键托盘只负责显示/聚焦，关闭窗口负责隐藏；macOS 永久无 Dock，Windows 仅隐藏窗口时退出任务栏。
- 桌面生命周期进入独立 Rust 模块，sidecar、后端配置和前端状态边界保持不变。
- 实现完成后将本文件归档到 `.agent-work/PLANS/{YYYYMMDD-HHMM}.md`。
