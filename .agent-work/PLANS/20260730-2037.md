# Codex Cockpit Lite 依赖升级与代码规范修复

## 目标

- 固定 Python 3.14.6、Node 24.18.1 LTS、Rust 1.97.1 及已核验的最新兼容依赖。
- 将 Python 后端改为标准包，并以 PyInstaller one-file + Tauri `externalBin` sidecar 交付。
- 保持现有 API、配置格式、动态端口和 WebUI 行为不变。
- 建立本地统一格式、lint、类型/框架检查、测试和构建门禁，不新增 CI。

## 实施步骤

1. 增加工具链版本文件，升级 npm、Cargo、Python 清单并生成锁文件。
2. 将后端迁入 `backend/src/codex_cockpit_lite/`，使用 Hatchling、uv 和正式 CLI 入口；移除重复清单与未使用依赖。
3. 增加跨平台 PyInstaller sidecar 构建脚本；先构建 Vite WebUI，再生成带目标三元组后缀的后端二进制。
4. 使用 Tauri shell plugin 从 Rust 异步启动 sidecar，解析 `PORT=<u16>`，保存精确子进程句柄并在退出时停止；移除系统 Python、PID 文件和猜测式进程清理。
5. 将 ureq 升级到 3.3，并保持 4xx/5xx JSON `detail` 到前端的错误文案透传。
6. 配置 Ruff、ESLint、Prettier、svelte-check；修复 Rust/Python/前端全部现有规范告警和弃用 API。
7. 删除 API Key/Agent Identity 死代码，只允许 `auth_mode == "chatgpt"`；保持内部 OAuth meta 格式。
8. 增加统一 `scripts/check.py`，更新构建文档和项目规则。

## 验收

- `uv sync --locked`、`npm ci`、Cargo `--locked` 成功。
- Ruff、pytest warnings-as-errors、Prettier、ESLint、svelte-check、Vitest、Vite、rustfmt、Clippy `-D warnings`、cargo test 全部通过且无警告。
- sidecar 冒烟测试覆盖状态端点、WebUI、端口递增、错误透传和进程退出。
- `npx tauri build --bundles app` 自动构建 sidecar 并覆盖 macOS `.app`。
- Windows 使用同一脚本在 Windows 主机原生构建，不在 macOS 交叉编译。
